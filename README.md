# 🎵 Melodia - Music Streaming App

Android Kotlin music streaming app with Firebase backend and GitHub song storage.

## 📁 Project Structure

```
melódia/
├── songs/                 # Song storage folder
│   ├── hindi/
│   ├── english/
│   └── regional/
├── app-code/             # Android Kotlin source code
├── firebase-config/      # Firebase configuration
└── docs/                 # Documentation
```

## 🎯 Features

- Stream songs from GitHub raw links
- Firebase Realtime Database for metadata
- Beautiful Kotlin UI
- Offline support

## 📝 Setup Guide

See `SETUP.md` for detailed instructions.

## 🚀 Quick Start

1. Upload songs to `songs/` folder
2. Get raw GitHub links
3. Store song metadata in Firebase
4. Integrate in Android app
